# Zephyrus showcase

Work only in this site repository. Neighboring framework and Leaf repositories are reference material.

- Build with the Zephyrus Leaf CLI. English is the default locale at `/`; French lives at `/fr/`.
- Put interface copy in `locale/en/general.json` and `locale/fr/general.json`. Translate documentation through `content/fr/`.
- Preserve the visual identity, logo and animated hero. Verify visible changes with headless Playwright and examine screenshots.
- Do not use em dashes in site content, templates or generated output.
- Ground framework capabilities in the actual core source. Documentation remains a preview until the core update is ready.
- Commits must use a semantic Conventional Commits subject, with no body and no co-author or other attribution trailers.
