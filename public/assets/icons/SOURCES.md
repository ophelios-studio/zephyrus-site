# Tabler Icons

Official outline SVGs from https://github.com/tabler/tabler-icons, version 3.49.0, retrieved 2026-10-09.

The original path geometry is assembled into a local SVG symbol sprite. Styling inherits the site color and stroke width. No icon font, CDN or runtime dependency is required.

Icons: arrow-up-right, arrows-split, brand-github, broadcast, copy, database-import, hierarchy-2, plug-connected, receipt, search, shield-check, stack-2, terminal-2, wallet, webhook.
